# VisionCast brand

The logo is a coral tile with a `>` and a dot. Read one way, it's a play button; read another, it's a code prompt; the dot is the live signal. Webinars, for the people who build websites.

## Files

| File | Use |
|---|---|
| `visioncast-logo.svg`, `visioncast-logo-light.png` | Full logo on light backgrounds |
| `visioncast-logo-dark.svg`, `visioncast-logo-dark.png` | Full logo on dark backgrounds |
| `visioncast-mark.svg`, `visioncast-mark-1024.png`, `visioncast-mark-512.png` | The mark alone: avatars, app icons, anywhere square |
| `visioncast-icon-small.svg`, `favicon.ico` | 32 px and below: heavier strokes so the dot survives |
| `visioncast-wordmark.svg` | The name alone, where the mark already appears |
| `social-preview-1280x640.png` | GitHub social preview (Settings › General › Social preview) |
| `social-card-1200x628.png`, `social-card-1080x1080.png` | Link previews and posts |

The SVGs are the masters. The wordmark is outlined, so it renders the same everywhere without the font installed.

## Type

The wordmark is [Fraunces](https://github.com/undercasetype/Fraunces) SemiBold at optical size 72, released under the SIL Open Font License 1.1. The studio's own headings use the system serif stack.

## Use it well

- Leave clear space around the logo at least as wide as the dot.
- Don't recolour the tile, stretch it, or put the full logo on a busy photo. Use the mark alone on small or busy surfaces.
- Below 32 px, use `visioncast-icon-small.svg`.
- The attendee-facing waiting room carries your customer's event, so it stays unbranded on purpose.
