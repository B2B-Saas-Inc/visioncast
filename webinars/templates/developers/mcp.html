MCP for coding agents

A Model Context Protocol server over stateless Streamable HTTP. One JSON-RPC message per POST, JSON responses, no SSE stream and no session id. Supported protocol versions: {% for v in versions %}{{ v }}{% if not forloop.last %}, {% endif %}{% endfor %}.

Connect

Endpoint: {{ endpoint }}. Authenticate every request with an API key from the studio. Tools are filtered by the key's scopes.

{
  "mcpServers": {
    "webinars": {
      "type": "http",
      "url": "{{ endpoint }}",
      "headers": { "Authorization": "Bearer ${WEBINAR_MCP_KEY}" }
    }
  }
}

Keep keys in environment variables, never in committed config. Use public_read for read-only agents and content_write only where an agent should edit drafts.

Handshake

curl -s {{ endpoint }} \
  -H "Authorization: Bearer $KEY" -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{"protocolVersion":"2025-06-18","capabilities":{},"clientInfo":{"name":"cli","version":"1"}}}'

# then: {"jsonrpc":"2.0","method":"notifications/initialized"}  -> 202
#       {"jsonrpc":"2.0","id":2,"method":"tools/list"}
#       {"jsonrpc":"2.0","id":3,"method":"tools/call","params":{"name":"list_events","arguments":{"when":"upcoming"}}}

Errors: -32700 parse, -32600 invalid request (batches unsupported), -32601 unknown method, -32602 bad params / unknown tool / scope. HTTP 401 without a valid key, 405 for GET. Tool failures return isError: true with the API error body.
