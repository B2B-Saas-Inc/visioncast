Build on the webinar platform

Read published events, embed registration forms, manage content from your CMS or CI, and let coding agents work through MCP. Everything uses scoped API keys created in the studio.

1. Create a key

Administrators create keys in Studio → API keys. The key is shown once; only its hash is stored. Send it as Authorization: Bearer wbk_….

2. Pick an interface

REST API: public catalogue, registration, management and waiting room. Machine-readable OpenAPI 3.1 at /api/v1/openapi.json.

MCP server at /mcp: typed tools for agents (list/get events, form schema, create and schedule content) bound to the same key scopes.

Form schema: GET /api/v1/forms/<version> returns canonical field keys, labels, types and options to render a registration form anywhere.

Example

curl -s https://YOUR-HOST/api/v1/events?when=upcoming
curl -s -H "Authorization: Bearer $WEBINAR_KEY" https://YOUR-HOST/api/v1/manage/events

Privacy guarantees. No endpoint returns a session's provider join link or registrants' personal data. Join links are revealed only by redirect to an admitted attendee in the hosted waiting room, and to webhook destinations that explicitly opt in.
