Tracking & GTM

One Google Tag Manager tag for your whole site. It loads the registration form script once, reads the visitor's consent from your dataLayer and recognises returning visitors on the forms you have embedded. It is not a page-view or analytics tracker.

What the tag does

  • Loads the script once. On every fire it checks for an existing window.WebinarForm and only injects the script element the first time, so duplicate triggers, GTM previews and single-page navigations never load it twice. If the first load fails (404 or blocked by your CSP) the next fire retries.
  • Binds embedded forms only. The script enhances form[data-webinar-form] elements that you pasted from a session's Embed on your site page. It never touches other forms, never pre-fills stored values and reads nothing on pages without an embedded form.
  • Recognises returning visitors (functional, not consent-gated). On every page with an embedded form the script calls GET {{ values.proxy_base }}/profile with the proxy's own first-party recognition cookie, with or without marketing consent, and hides the fields the visitor already gave. That cookie and the CSRF cookie are functional; no values are pre-filled.
  • Consent gates attribution. With consent denied, nothing from the URL, the referrer or third-party cookies is kept or sent. With analytics consent it sends UTM parameters, the _ga cookie's client ID and the origin + path of the page and of the referrer. With advertising consent it sends ad click IDs and the matching first-party ad cookies. All of it goes only in the registration request when the visitor submits.
  • Reads consent, never code. The tag contains no GTM variable references. It looks at the newest dataLayer message with your consent key and compares the two values as plain text. A quote, newline or script in that message is just a value and counts as denied; it is never executed.
  • One dataLayer event. After a successful registration, and only with analytics consent, it pushes webinar_registration with the occurrence ID and form version. No personal data is pushed.

Install in GTM

  1. Serve the proxy first. Route {{ values.proxy_base }}/* on your site to the first-party proxy (sdk/proxy/server.js or an equivalent same-origin route), with PROXY_API_KEY set to a proxy-scoped key from API keys and PROXY_ALLOWED_ORIGINS set to your exact https origin. The key stays on the server, never in GTM.
  2. Push consent to the dataLayer (if reading from your consent platform): from your CMP's callback, push the message shown under “What your consent platform must push” once consent is resolved and again on every change, with the key {{ values.consent_key }} and the event name {{ consent_event }} (or the event your site already uses for consent updates). The tag never reads anything else from the dataLayer.
  3. Create a Custom HTML tag, paste the tag above, and tick “Support document.write” off. Give it two triggers: All Pages – DOM Ready (or Initialization if your CMP resolves consent before it) and a Custom Event trigger on {{ consent_event }} (or the matching event your CMP pushes after consent changes). Under Advanced settings leave Tag firing options at Unlimited: with “Once per page”, consent changes after load would be swallowed.
  4. Single-page apps. Fire the tag on a custom dataLayer event your app pushes after the view containing the form has rendered, or call window.WebinarForm.init() yourself after render. A History Change trigger alone usually fires too early (before the form is in the DOM) and only works for routers that render synchronously.
  5. Preview. In GTM Preview, open a page with an embedded form. The tag should fire once on load and again on each consent update. In the browser's network panel you should see GET {{ values.proxy_base }}/profile succeed; a 404 or 403 there means the proxy route or origin is not set up yet. If the tag shows as fired but no /profile request appears and the console reports the script blocked by Content Security Policy, allow the script host{% if custom_script_host %} ({{ custom_script_host }}){% endif %} in script-src; the next fire retries the load.
  6. Embed forms per session. Open a session and choose Embed on your site to copy the form markup. With this site-wide tag installed, remove the <script src> line from that snippet. If it is left in place, that script boots first and the proxy path set here is ignored ({{ defaults.proxy_base }} is used); consent from this tag still applies and the console warns about it.
